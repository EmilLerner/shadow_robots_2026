Final haptics code for both EMS and air bladder. The double bladder (most recent) means there are separate bladders for both input and output with EMS included. The haptics was the first version when the EMS was introduced but uses only one bladder. Both versions require an additional esp32 connected to the computer running the python code. 


Put esp1 code on an esp32 connected to the computer through USB. Make sure that the mac address on
the ESPCommunication matches the esp32 connected to the computer and the mac address in the esp1 file matches the main esp32
